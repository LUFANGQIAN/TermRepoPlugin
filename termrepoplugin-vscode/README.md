# TermRepoPlugin-VSCode

一个面向开发者术语积累与复用的 VS Code 扩展。

它解决的不是“查词”本身，而是把你在阅读代码、命名变量、维护项目时遇到的术语，沉淀为可持续复用的个人词库。你可以收藏代码中的单词，补充备注和拆词解释，在侧边栏统一管理，并通过固定触发符快速检索后直接替换到编辑器里。

## 项目简介

TermRepoPlugin-VSCode 当前已经具备一个完整的本地词库闭环：

- 收藏：从编辑器选中单词直接加入词库，也支持手动录入
- 理解：自动拆分标识符，并为每个片段补充备注与标签
- 管理：在侧边栏 Webview 中搜索、新增、编辑、删除词条
- 复用：输入固定符号后，直接从词库搜索并插入单词
- 迁移：支持将词库导出为 JSON，并重新导入

它尤其适合下面这些场景：

- 阅读源码时，遇到值得记住的变量名、函数名、领域词汇
- 写代码命名时，只记得中文语义，想快速找回自己沉淀过的英文表达
- 团队逐步整理一套更统一的技术命名习惯
- 非英语母语开发者做长期术语积累

## 当前功能

### 1. 收藏单词

- 支持从编辑器选区直接收藏单词
- 支持无选区时手动输入单词
- 自动记录来源文件相对路径
- 自动拆分 `camelCase` / `snake_case` 标识符
- 为整体单词和拆分片段填写备注
- 自动生成基础标签

### 2. 管理词库

- 侧边栏提供 Webview 词库管理界面
- 支持顶部搜索栏按单词、备注、标签检索
- 支持新增词条
- 支持进入二级页面编辑词条
- 支持删除词条前确认
- 支持复制单词内容
- 支持打开插件配置入口

### 3. 复用单词

- 支持通过固定触发符检索词库
- 输入触发符后直接搜索本地词条
- 选中候选项后替换当前输入片段
- 搜索范围覆盖单词本身、整体备注、标签、拆分备注

示例：

```txt
%router
```

当触发符为 `%` 时，输入上述内容即可在补全面板中搜索与 `router` 相关的词条，并直接插入目标单词。

### 4. 导入与导出

- 支持将当前词库导出为 JSON 文件
- 支持从导出的 JSON 文件重新导入
- 导入时会跳过已存在的重复词条

## 使用方式

### 收藏一个单词

1. 在编辑器中选中一个标识符
2. 执行命令 `TermRepoPlugin: 收藏选中单词`
3. 按提示填写整体备注与拆词备注
4. 词条会写入本地词库，并同步显示在侧边栏中

### 在侧边栏管理词库

1. 打开 VS Code 左侧 Activity Bar 中的 TermRepo 侧边栏
2. 通过顶部搜索栏筛选词条
3. 点击词条或编辑按钮进入二级编辑页
4. 在编辑页中完成保存、复制或删除

### 在编辑器中快速复用单词

1. 输入触发符，例如 `%`
2. 继续输入关键词，例如 `%auth`
3. 在补全面板中选择目标词条
4. 选中后会直接替换当前输入片段

### 导入或导出词库

- 可通过侧边栏顶部按钮导入或导出
- 也可通过命令面板或右键菜单执行导入导出命令

## 命令列表

| 命令 ID | 说明 |
| --- | --- |
| `termrepoplugin-vscode.addWord` | 收藏选中单词 |
| `termrepoplugin-vscode.showAllWords` | 显示所有单词并支持快速复制 |
| `termrepoplugin-vscode.exportWords` | 导出单词库 |
| `termrepoplugin-vscode.importWords` | 导入单词库 |
| `termrepoplugin-vscode.printSelection` | 打印当前选区内容，便于调试 |

默认快捷键：

- `Alt+Q`：收藏当前选中的单词

## 配置项

当前已开放的插件配置如下：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `termrepoplugin-vscode.triggerSymbol` | `string` | `%` | 输入该符号后，从词库中搜索并替换单词 |
| `termrepoplugin-vscode.favoriteKeybinding` | `string` | `Alt+Q` | 收藏单词的目标快捷键，修改后插件会引导你到 VS Code 键盘快捷方式中完成实际绑定 |

你也可以在侧边栏顶部点击“插件设置”直接跳转到对应配置项。

## 数据存储

插件当前使用本地 JSON 文件保存词库数据，存储位置由 VS Code 的全局存储目录分配。实际数据文件名为：

```txt
termrepo-data.json
```

词条数据包含以下关键信息：

- 原始单词
- 整体备注
- 来源文件路径
- 拆词片段及片段备注
- 标签
- 创建与更新时间
- 预留的复习相关字段

## 项目结构

当前代码结构已经按职责做了基础拆分，便于继续扩展：

```txt
termrepoplugin-vscode/
├─ src/
│  ├─ commands/      # 命令注册与命令实现
│  ├─ providers/     # 编辑器补全与替换能力
│  ├─ storage/       # 本地词库存储
│  ├─ types/         # 业务类型定义
│  ├─ utils/         # 拆词、标签、复制等工具
│  ├─ views/         # 侧边栏 Webview
│  ├─ extension.ts   # 扩展激活入口
│  └─ index.ts       # 项目统一公共导出入口
├─ docs/             # TypeDoc 生成文档
├─ package.json      # 扩展清单与配置项
└─ typedoc.json      # 文档生成配置
```

其中 `src/index.ts` 已被整理为统一公共导出入口，便于阅读源码与生成文档。

### 环境要求

- Node.js 18 及以上
- VS Code 1.110.0 及以上

### 安装依赖

```bash
npm install
```

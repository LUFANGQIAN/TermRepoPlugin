# 各功能实现思路

## 1. 扩展启动与总入口

- 入口文件是 `src/extension.ts`。
- 激活时先创建 `StorageManager`，把全局存储目录中的词库 JSON 加载到内存。
- 然后依次注册三类能力：
  - 命令系统
  - 编辑器补全替换
  - 侧边栏 Webview
- 三者共用同一个 `StorageManager` 实例，保证数据源一致。

## 2. 词库存储

- 存储核心在 `src/storage/StorageManager.ts`。
- 运行时使用 `Map` 保存：
  - `terms`：完整词条
  - `suggestions`：拆分项备注的学习数据
- 落盘格式是 `termrepo-data.json`，结构大致为：

```json
{
  "version": 1,
  "terms": {},
  "suggestions": {}
}
```

- 这样设计的好处：
  - 内存操作方便
  - 磁盘文件可读
  - 后续升级版本时可通过 `version` 做兼容

## 3. 单词收藏流程

- 收藏入口命令在 `src/commands/addWord.ts`。
- 执行流程：
  1. 优先读取编辑器选中的文本
  2. 若没有选中，则弹出输入框手动输入
  3. 调用 `askForTermDetails` 采集整体备注与拆分项备注
  4. 生成完整 `TermEntry`
  5. 写入 `StorageManager`
  6. 更新拆分项备注建议数据
  7. 自动复制原单词到剪贴板

## 4. 拆分与备注采集

- 逻辑在 `src/utils/termUtils.ts`。
- `splitIdentifier` 负责拆分标识符：
  - 下划线命名
  - 驼峰命名
- `askForTermDetails` 负责交互式收集一个完整词条。
- 备注建议来源有两层：
  - 动态建议：来自用户历史输入的 `suggestions`
  - 静态建议：来自 `wordSuggestions.ts`

## 5. 词库展示与管理界面

- 侧边栏视图由 `src/views/MyWebviewProvider.ts` 提供。
- 页面分成两级：
  - 一级：列表页，用来搜索、查看、进入编辑
  - 二级：详情页，用来新增、编辑、删除、复制
- Webview 与扩展主进程通过 `postMessage` 通信。
- 所有增删改操作最终都会回落到 `StorageManager`。

## 6. 编辑器内快速替换单词

- 功能实现在 `src/providers/termCompletionProvider.ts`。
- 当前机制是“固定符号 + 关键词”触发，例如：

```txt
;router
```

- 触发后会：
  1. 从当前行光标左侧提取触发串
  2. 在词库中做模糊匹配
  3. 生成补全列表
  4. 选中后把整段触发串替换为目标单词

- 固定符号支持在设置项 `termrepoplugin-vscode.triggerSymbol` 中修改。

## 7. 导入与导出

### 导出

- 命令文件：`src/commands/exportWords.ts`
- 将当前全部词条导出为一个 JSON 文件。
- 导出文件包含：
  - 导出时间
  - 词条数量
  - 词条数组

### 导入

- 命令文件：`src/commands/importWords.ts`
- 从 JSON 文件中读取 `terms` 数组并恢复成 `TermEntry`。
- 导入时会：
  - 校验基本字段
  - 过滤非法数据
  - 自动跳过重复单词

## 8. 搜索与复制

- “显示所有单词”命令：`src/commands/showAllWords.ts`
- “复制单词”命令：`src/commands/copyWord.ts`
- 两者都围绕 `StorageManager` 做轻量读取，不额外维护状态。
- 剪贴板统一通过 `src/utils/clipboard.ts` 封装。

## 9. 插件配置入口

- 配置项定义在 `package.json` 的 `contributes.configuration` 中。
- 目前已支持：
  - `termrepoplugin-vscode.triggerSymbol`
- Webview 顶部配置菜单会提供：
  - 导入词库
  - 导出词库
  - 打开插件设置

## 10. 代码组织思路

- `commands/`：命令入口，负责用户动作
- `providers/`：编辑器能力扩展，例如补全
- `storage/`：数据持久化
- `utils/`：拆分、标签、剪贴板等工具函数
- `views/`：侧边栏 Webview
- `types/`：统一数据结构定义

这样的分层可以让项目后续继续扩展，例如：

- 增加复习模式
- 增加词条标签筛选
- 增加导入格式兼容
- 增加云同步能力

# TermRepoPlugin 测试版试用说明

这是一版用于小范围试用的 VS Code 扩展测试包，欢迎帮忙体验并反馈问题。

## 安装方式

1. 打开 VS Code
2. 按 `Ctrl+Shift+P`
3. 输入并执行 `Extensions: Install from VSIX...`
4. 选择收到的 `termrepoplugin-vscode-0.0.1.vsix`
5. 安装完成后按提示重载 VS Code

## 建议重点体验

可以重点帮我试下面这些功能：

- 在编辑器中选中单词后使用 `Alt+Q` 收藏
- 在左侧侧边栏打开 TermRepo 词库管理界面
- 搜索、新增、编辑、删除词条
- 导出词库，再重新导入
- 输入触发符 `%` 后搜索并替换词库中的单词
- 修改插件设置中的触发符和收藏快捷键

## 快速上手

- 默认收藏快捷键：`Alt+Q`
- 默认触发符：`%`
- 侧边栏中可以管理词库、导入导出、打开插件设置

    • activate(context: ExtensionContext): Promise<void>

      扩展激活入口。

      这里负责串联整个插件的三条主链路：

      1. 初始化本地词库存储。
      2. 注册命令、编辑器补全替换能力和侧边栏视图。
      3. 将所有运行时能力绑定到同一个 StorageManager 实例上， 保证命令面板、编辑器补全和 Webview 访问的是同一份数据。

      参数

      • context: ExtensionContext

        VS Code 在激活扩展时提供的上下文对象。

      返回 Promise<void>

    类 StorageManager

    词库存储管理器。

    该类负责：

    • 管理单词与拆分建议的内存态缓存
    • 在 JSON 文件与运行时 Map 结构之间转换
    • 暴露增删改查接口
    • 在数据变化时向视图层广播刷新事件
